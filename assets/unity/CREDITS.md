The official page states the rig is free to use with attribution and is compatible with Blender 4.1 and later. It includes an embedded Python rig interface; downloading and extracting this archive did not execute that code.

For the separate Borrowed Time visual study, the character's materials were adapted to a muted palette. Original running, jumping, landing, and lane-switching animation was created for this study, along with a custom tunnel, lighting, and rear-following camera. The character's underlying model, textures, and rig remain credited to Blender Studio / Blender Foundation. These adaptations are not endorsed by Blender Studio or the Blender Foundation. Preserve this attribution when sharing the study or adapted character.

The original downloaded archive and extracted source remain available alongside the study so adaptations can be distinguished from the original asset.

# Surface assets

Downloaded from the official Poly Haven API; each source file checked against the API MD5.

- Concrete Floor Worn 001 — Dimitrios Savva / Rico Cilliers — https://polyhaven.com/a/concrete_floor_worn_001 — CC0.
- Brick Floor 02 — Charlotte Baglioni — https://polyhaven.com/a/brick_floor_02 — CC0.

Adaptations: base-color saturation/contrast reduced for the study palette; roughness converted to URP smoothness alpha; normal maps remain OpenGL normals. No game assets from INSIDE are used.

The V5 game integrates these adaptations. The jacket and hair silhouette, procedural pose sequence, tunnel architecture and camera were created for Borrowed Time. INSIDE is a visual reference; no assets or animations were extracted from that game.
