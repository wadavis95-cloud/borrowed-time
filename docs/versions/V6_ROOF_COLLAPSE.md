# V6 roof collapse and approach timing

The roof starts covered. Hazard locations now have detachable curved masonry panels and matching arch segments. A warning opens thin cracks and shakes the panel; at fall start the panel leaves the ceiling, its matching slab falls and tumbles, and impact produces rubble and dust. The opening persists for the rest of the race and exposes a blue sky above the tunnel. Rematches reconstruct intact panels for the new course. The existing bright exit and lighting remain.

The previous hazard schedule assumed an unboosted, uninterrupted run. Boosting could therefore carry a runner past before the roof fell. Generated hazards now check approaching runners over the next 2.55 seconds, integrating acceleration, current boost duration, stun duration and the speed cap. Impact targets 0.15 seconds before the earliest predicted arrival. A subsequent boost can advance an already warned event; events are never postponed. The normal falling phase is 0.65 seconds. Existing fixed-time custom fixtures retain their explicit schedule. Slowing down after a collapse has been committed can mean reaching already landed rubble.

Solo updates its own schedule. Online rooms evaluate all runners before advancing any player, then publish the same explicit world-event timings to every client. The frontend uses these server timings rather than regenerating the original schedule from the seed. Private balances and purchase flags remain private. World-event snapshots contain only ID, lane, position and warning/fall/impact times.

The 13-fall sample course, lane rules, prices and hit penalties remain unchanged. This is timed environmental animation tied to real collision rules, rather than a structural destruction physics simulation. The optional Unity experiment retains its previous roof presentation; the default Three.js game contains this update.

Verification: 103 standard tests passed (nine socket checks skipped in that run); all 29 network tests passed separately. Coverage includes normal and boosted arrivals, a boost after a warning, shared server schedules, public field boundaries, and client use of changed timings. Real Three.js raycasts verify intact roofing, sky openings in all three lanes, persistent holes and rematch restoration. The 128-course free-route check still passes. A browser sequence captured the visible sky opening during actual play. Public deployment is unchanged.
