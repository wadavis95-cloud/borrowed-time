    UNDER THE HOOD

    A game loop you can understand.

    This game uses JavaScript, HTML, CSS, and Three.js for 3D graphics. Node.js serves the files and runs multiplayer races. The ws package keeps browsers connected to the server.

    1. 01
      You press a button

      src/main.js listens to the keyboard, touch controls, and ability buttons.

    2. 02
      The server checks your action

      In multiplayer, src/network.js sends the button press. The server uses src/game.js to charge time, move you, and check obstacles. Solo practice runs these same rules in your browser.

    3. 03
      The world gets drawn

      src/renderer.js uses Three.js to draw the tunnel, animated runner, and debris. The environment grows lighter as you approach the exit.

    4. 04
      Keep everyone in the same race

      The server sends updated positions 20 times per second. Your browser smooths the motion and draws other runners as transparent models. It receives your own stats, but no opponent timers or ability status.

    Your avatar is assigned automatically and stays with you for rematches. Amber ground markers warn of falling stone: switch lanes before impact, then hop the rubble left behind. Multiplayer races keep running when you switch tabs or open this guide. Rooms last only while the server is running; there are no accounts or saved leaderboards.
